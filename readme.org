#+title: Literate environment configuration
#+author: piotr-yuxuan
#+language: en

Declarative system configuration for a *Framework 16 AMD 7040* (NixOS,
=nixOS=) and a *macOS work laptop* (nix-darwin, =macOS=).

Both machines share a common base of CLI tools, fonts, Zsh, Git, GPG,
and Emacs tooling via Home Manager.  Platform-specific layers sit on
top.

* Start here

- [[file:docs/tutorials/first-day-on-a-new-mac.org][First day on a new Mac]]: install Nix, Homebrew and nix-darwin on a
  fresh Apple Silicon Mac and switch to this configuration from a
  small flake of its own.
- [[file:docs/tutorials/install-nixos-on-the-framework-16.org][Install NixOS on the Framework 16]]: partition with Disko, install
  NixOS from an Ubuntu live USB and enrol Secure Boot keys.
- [[file:docs/how-to/troubleshoot-common-problems.org::*Symptom index][Symptom index]]: something is broken; find the symptom and its fix.
- [[file:AGENTS.md][AGENTS.md]]: the workflow, testing and style rules for agents that
  change this repository.
- [[file:tests/README.org][Testing conventions]]: how the BATS and pytest suites are organised and
  run.

* Documentation map

The pages follow [[https://diataxis.fr/][Diátaxis]]: tutorials teach by doing, how-to guides
solve a specific problem, reference describes the machinery and
explanation discusses why.  Host-specific pages carry a =nixOS-= or
=macOS-= prefix.
