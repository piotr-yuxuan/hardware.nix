#+title: Getting started on macOS
#+author: piotr-yuxuan

We target =aarch64-darwin= (Apple Silicon).
Installation requires administrator privileges and internet access. Grant
additional application permissions only when a specific operation needs them.

- Homebrew could install it but the graphical downloader gives an
  estimated time and a progress bar.

#+begin_src zsh
xcode-select --install
#+end_src

- Install Nix, or Lix later if you want:

#+begin_src zsh
sh <(curl -L https://nixos.org/nix/install)
#+end_src

- Install Homebrew

#+begin_src zsh
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
eval "$(/opt/homebrew/bin/brew shellenv)"
#+end_src

Open a *new terminal* when you reach this stage.

- Clone the configuration

#+begin_src zsh
git clone https://github.com/piotr-yuxuan/hardware.nix.git ~/src/github.com/piotr-yuxuan/hardware.nix
cd ~/src/github.com/piotr-yuxuan/hardware.nix
#+end_src

- The flake is currently pinned to the macOS user =example= and a specific Git
  identity in =home/macOS.nix=. If you are bootstrapping a different machine,
  update those values first.

- On the first run you need to install nix-darwin:

#+begin_src zsh
sudo nix --extra-experimental-features "nix-command flakes" run nix-darwin -- switch --flake '.#macOS'
#+end_src

On the first nix-darwin install, because it runs after nix install
that updates terminal config files in =/etc/=, you may be prompted to
run:

#+begin_src zsh
sudo mv /etc/bashrc /etc/bashrc.before-nix-darwin
sudo mv /etc/zshrc /etc/zshrc.before-nix-darwin
#+end_src

- Once it completes, restart macOS and untick the box 'Reopen windows
  when logging in'.

- On subsequent rebuilds you may simply use:

#+begin_src zsh
sudo darwin-rebuild switch --flake '.#macOS'
#+end_src

- Clone Emacs configuration:

#+begin_src zsh
git clone --depth 1 https://github.com/piotr-yuxuan/.emacs.d ~/src/github.com/piotr-yuxuan/.emacs.d
ln -s ~/src/github.com/piotr-yuxuan/.emacs.d ~/.emacs.d
#+end_src

- Create or import GPG and SSH keys
- Create =~/.zshenv.secrets= with tokens (e.g. =GITLAB_PERSONAL_ACCESS_TOKEN=)
- Launch Emacs and let it install packages

* Notes

** Nix-managed Homebrew

Some macOS GUI apps (Emacs.app via jimeh/emacs-builds, Firefox, Slack,
VS Code, etc.) work more reliably as native =.app= bundles installed
through Homebrew casks. A few CLI tools that are not well-packaged in
nixpkgs for macOS (e.g. =texlive=, =lft=) also stay in Homebrew.

The Home Manager activation script runs =brew bundle install= from
=config/Brewfile= automatically on every =darwin-rebuild switch=, so
both worlds stay in sync.

The Home Manager activation also runs =brew update && brew bundle
install= from =config/Brewfile=, so Homebrew casks (Firefox, Emacs,
VS Code, etc.) are installed automatically.
