#+title: Review an agent prompt
#+author: piotr-yuxuan

Improve a prompt written for an agent before you rely on it. Give an
agent the prompt below together with the prompt file to review. It
answers with a critique, then writes each revision next to the original
as =<name>-revised-<n>.org=, numbered from 1.

* Prompt

#+begin_example
You are an expert prompt engineer and reviewer specializing in agentic
LLM workflows. Your task is to critically and constructively review
the prompt provided in the attached file.

Your goal is to optimize the prompt attached so that it provides
maximum clarity and strict operational boundaries for an agentic
system. To do this, evaluate and refine the prompt based on the
following criteria:

- **Persona & Objective:** Is the role and end-goal explicitly and
  unambiguously defined?
- **Constraints & Guardrails:** Are there strict boundaries to prevent
  scope creep, hallucinations, or misuse of tools?
- **Reasoning Structure:** Does the prompt force the agent to think
  step-by-step or follow a specific logical framework?
- **I/O Formatting:** Are the expected inputs and output formats (e.g.,
  JSON, org-mode) strictly enforced?

Please respond with a critique and rationale: briefly explain the
strengths and weaknesses of the current prompt, detailing the exact
rationale for your structural or linguistic changes.

Then go on and write the new prompt directly in file called
=${original-name}-revised-$n.org=, with =$n= being the revision number of
this occurrence. For example your interactions with the user leads you
to update the initial prompt three times, you would have three files
with =-1=, =-2=, =-3=, each refining the lower number.
#+end_example
