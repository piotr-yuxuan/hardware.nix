* Z-shell                                                              :tty:

** History configuration

Large, deduplicated, shared history is one of the highest-leverage
shell tweaks. These options are set in =config/after.zshrc= via Home
Manager now, but the reasoning still applies.

#+begin_src zsh
export HISTSIZE=10000000
export HISTFILESIZE=100000000
export HISTTIMEFORMAT="%d/%m/%y %T "

setopt EXTENDED_HISTORY          # Write ":start:elapsed;command" format.
setopt INC_APPEND_HISTORY        # Write immediately, not on shell exit.
setopt SHARE_HISTORY             # Share history between all sessions.
setopt HIST_EXPIRE_DUPS_FIRST    # Expire duplicates first when trimming.
setopt HIST_IGNORE_DUPS          # Don't record consecutive duplicates.
setopt HIST_IGNORE_ALL_DUPS      # Delete old entry if new is a duplicate.
setopt HIST_FIND_NO_DUPS         # Don't display previously found lines.
setopt HIST_IGNORE_SPACE         # Don't record entries starting with a space.
setopt HIST_SAVE_NO_DUPS         # Don't write duplicate entries to the file.
setopt HIST_REDUCE_BLANKS        # Remove superfluous blanks before recording.
#+end_src

* SSH configuration

Express only connection-specific settings here. Git SSH keys are
handled through gitconfig's =includeIf= and per-host =IdentityFile= lines.

Home Manager's =programs.ssh= generates =~/.ssh/config= on both
platforms, so edit =home/base.nix= or =home/<host>.nix= rather than
the generated file, or the machine's own files for a setting of one
machine.  The shared =Host *= block looks like this on macOS,
which adds =UseKeychain= so that Apple's ssh keeps key passphrases in
the login Keychain:

#+begin_src ssh-config
Host *
  AddKeysToAgent yes
  ControlMaster auto
  ControlPath ~/.ssh/control-%C
  ControlPersist 10m
  ForwardAgent no
  HashKnownHosts yes
  IdentitiesOnly yes
  PasswordAuthentication no
  ServerAliveCountMax 3
  ServerAliveInterval 60
  StrictHostKeyChecking accept-new
  UseKeychain yes
#+end_src

With =IdentitiesOnly yes=, ssh offers only the keys that a host block
or the command line names.  Each machine has its own personal GitHub
key and names it in its own files:

- nixOS adds a =Host github.com= block with an =IdentityFile=, in its
  personal module (see
  [[file:nixOS-personalise-a-fresh-install.org][Personalise a fresh install of nixOS]]).
- A Mac has no =Host github.com= block, so the personal key is never
  offered to work repositories.  A =gitdir:~/src/github.com/piotr-yuxuan/=
  include in the Mac's own =identity.nix= selects the key per directory
  instead:

  #+begin_src gitconfig
  [core]
      sshCommand = ssh -i ~/.ssh/piotr-yuxuan@users.noreply.github.com_ed25519 -o IdentitiesOnly=yes -o ControlPath=none
  #+end_src

  =ControlPath=none= stops Git from reusing a connection that another
  key authenticated.

On macOS, name the personal key explicitly to test it, and clone
personal repositories into =~/src/github.com/piotr-yuxuan/=, where Git
applies the include while it clones:

#+begin_src zsh
ssh -i ~/.ssh/piotr-yuxuan@users.noreply.github.com_ed25519 \
  -o IdentitiesOnly=yes -T git@github.com
git clone git@github.com:piotr-yuxuan/<repository>.git \
  ~/src/github.com/piotr-yuxuan/<repository>
#+end_src

Only a clone into another directory needs the key named explicitly:

#+begin_src zsh
GIT_SSH_COMMAND='ssh -i ~/.ssh/piotr-yuxuan@users.noreply.github.com_ed25519 -o IdentitiesOnly=yes' \
  git clone git@github.com:piotr-yuxuan/<repository>.git <directory>
#+end_src

** Change directory to frontmost Finder window

#+begin_src zsh
pfd () {
    currFolderPath=$( /usr/bin/osascript <<EOT
        tell application "Finder"
            try
                set currFolder to (folder of the front window as alias)
            on error
                set currFolder to (path to desktop folder as alias)
            end try
            POSIX path of currFolder
        end tell
EOT
    )
    cd "$currFolderPath"
}
#+end_src

* fzf worked examples

The key bindings are listed in
[[file:../reference/shell-key-bindings.org::*fzf, command-line fuzzy finder][shell key bindings]].

Interactively pick a file and open it in your =EDITOR=:
#+begin_src zsh
$EDITOR $(fzf)
#+end_src

Kill one or more processes (=Tab= to multi-select, =Enter= to kill):
#+begin_src zsh
kill -9 $(ps aux | fzf --multi | awk '{print $2}')
#+end_src

Check out a git branch:
#+begin_src zsh
git checkout $(git branch -a | fzf)
#+end_src

Fuzzy-grep then open the match at the right line (relies on =bat= preview
showing the highlighted line before you commit):
#+begin_src zsh
rg --line-number '' \
  | fzf --delimiter ':' --nth 1,3.. \
        --preview 'bat --color=always --highlight-line {2} {1}' \
  | awk -F: '{print "+"$2, $1}' \
  | xargs $EDITOR
#+end_src

Copy a selected path to the Wayland clipboard:
#+begin_src zsh
fzf | wl-copy
#+end_src

* Generate a gif from a screen record

#+begin_src zsh
function gifgo {
  ffmpeg -i "$1" -pix_fmt rgb24 -r 10 -s 900x600 -f gif - \
    | gifsicle --delay=15 --optimize=3 > "$1.gif"
}
#+end_src

* Query structured data

** Grep JSON with gron

#+begin_src zsh
# brew install gron  /  nix-shell -p gron
gron "https://api.github.com/repos/tomnomnom/gron/commits?per_page=1" \
  | fgrep "commit.author" \
  | gron --ungron

* Reduce the size of a music library

Extract audio from video containers:

#+begin_src zsh
# Single file
if ffmpeg -i a.mkv -vn -acodec copy a.ogg; then
    rm a.mkv
else
    echo "Failed for a.mkv"
fi

# All MKV files recursively
find . -type f -name "*.mkv" -exec bash -c '
  FILE="$1"
  if ffmpeg -i "$FILE" -vn -acodec copy "$FILE.ogg"; then
      rm "$FILE"
  else
      echo "Failed for $FILE"
  fi
' _ '{}' \;
#+end_src

Ogg is a container format that can embed audio in various codecs
without re-encoding, so quality stays the same.  Typical size
reduction from MKV: ~66%.
