#+title: macOS configuration
#+author: piotr-yuxuan

What the =macOS= configuration manages on an Apple Silicon Mac: the
files that define it, the order in which a switch applies it, the
launchd jobs it installs, what it writes outside the Nix store, the
values each Mac fills in, and its evaluation check. A Mac builds the
configuration from a small flake of its own that calls this
repository's builder; this repository never holds a value of one Mac.
Values were checked against the configuration on 10 October 2026, by
evaluation on Linux. For the reasons behind them,
see [[file:../explanation/macOS-nix-and-homebrew.org][Why the Mac uses both Nix and Homebrew]] and
[[file:../explanation/macOS-git-identities.org][Why the Mac separates work and personal Git identities]]. For procedures, see
[[file:../tutorials/first-day-on-a-new-mac.org][First day on a new Mac]] and the =macOS-= how-to guides.

* Activation order

=sudo darwin-rebuild switch --flake '.#macOS'=, run from the Mac's
local flake, builds the system, then runs its =activate= script as
root. The script starts from an empty
environment (=#!/usr/bin/env -i=) and sets its own =PATH=, so variables
from the calling shell, such as =HOMEBREW_*= or a proxy, do not reach
activation.

** nix-darwin steps

The steps run in this order. Steps that have nothing to do in this
configuration (=extraActivation=, =patches=, =time=, =power=,
=keyboard=, =nvram= and =homebrew=, since =homebrew.enable= is false)
are left out.

| Step             | Effect in this configuration                                                                                                                                  |
|------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| =preActivation=  | Creates =/var/lib/linux-builder=                                                                                                                              |
| =checks=         | Aborts on a missing primary user, a Determinate Nix install, build users or group with unexpected IDs, a single-user install, or unrecognised files in =/etc= |
| =createRun=      | Ensures =/run= through a =run= line in =/etc/synthetic.conf=                                                                                                  |
| =groups=         | Group =nixbld= (GID 350)                                                                                                                                      |
| =users=          | Build users =_nixbld1= to =_nixbld32= (UIDs from 351)                                                                                                         |
| =applications=   | Copies =.app= bundles from =environment.systemPackages= to =/Applications/Nix Apps=                                                                           |
| =pam=            | =/etc/pam.d/sudo_local= with Touch ID                                                                                                                         |
| =openssh=        | Generates =/etc/ssh/ssh_host_{rsa,ecdsa,ed25519}_key= when missing                                                                                            |
| =etc=            | Points =/etc/static= at the new system and links the managed =/etc= files                                                                                     |
| =defaults=       | System preference domains (=/Library/Preferences/com.apple.loginwindow=)                                                                                      |
| =userDefaults=   | Preference domains of the primary user: every other =system.defaults= domain                                                                                  |
| =launchd=        | Daemons in =/Library/LaunchDaemons=                                                                                                                           |
| =userLaunchd=    | nix-darwin user agents in =~/Library/LaunchAgents=                                                                                                            |
| =nix-daemon=     | Renames =/etc/nix/nix.custom.conf= if present; reloads the daemon when =nix.conf= or =machines= changed                                                       |
| =networking=     | Application firewall settings through =socketfilterfw=                                                                                                        |
| =fonts=          | Copies the =fonts.packages= fonts to =/Library/Fonts/Nix Fonts=                                                                                               |
| =postActivation= | Runs =scripts/darwin-post-activation.sh=, then the Home Manager activation of the primary user                                                                |

The script then points =/run/current-system= at the new generation.

The last part of =postActivation= runs the Home Manager activation as
the primary user, through =launchctl asuser= and =sudo -u= with the
user's home. Its entries run in this evaluated order:

|     2 | =checkLinkTargets=             | before =writeBoundary=                    | Home Manager                         |
|     3 | =writeBoundary=                |                                           | Home Manager                         |
|     4 | =createGpgHomedir=             | after =writeBoundary=                     | =programs.gpg=                       |
|     5 | =migrateGhAccounts=            | after =writeBoundary=                     | =programs.gh=                        |
|     6 | =linkGeneration=               | after =writeBoundary=                     | Home Manager: links managed files    |
|     7 | =batCache=                     | after =linkGeneration=                    | =programs.bat=                       |
|     8 | =brewBundle=                   | after =writeBoundary=                     | [[file:../../home/macOS.nix][home/macOS.nix]]                       |

|    10 | =clojureMcpInstall=            | after =writeBoundary=                     | [[file:../../home/base.nix][home/base.nix]]                        |
|    11 | =installPackages=              | after =writeBoundary=                     | Home Manager                         |
|    12 | =copyApps=                     | after =installPackages=, =linkGeneration= | =targets.darwin.copyApps=            |
|    13 | =defaultApps=                  | after =brewBundle=                        | [[file:../../home/macOS.nix][home/macOS.nix]]                       |

=homeLayoutMacOS=, comes from the sort and is not a contract.

** Homebrew steps

=brewBundle= runs [[file:../../scripts/brew-bundle-activation.sh][scripts/brew-bundle-activation.sh]] with =BREWFILE=
set to the store copy of =config/Brewfile=. In order:

1. Skips everything, successfully, when =/opt/homebrew/bin/brew= does
   not exist.
2. Exports =HOMEBREW_NO_ASK=1=.
3. =brew update=; a failure is reported and ignored.
4. =brew install --cask --adopt docker-desktop= when
   =/Applications/Docker.app= exists but the cask is not installed.
5. =brew bundle install --file "$BREWFILE" --upgrade=. On failure the
   script stops here with success, so steps 6 to 8 do not run.
6. =brew upgrade --greedy=; a failure is reported and ignored.
7. =brew bundle cleanup --file "$BREWFILE"= with no standard input. When
   it reports drift and =/dev/tty= is readable, a menu offers =[u]=,
   =[e]= and =[s]=.
8. =brew cleanup --prune=all -v=; a failure is reported and ignored.

Each step is announced by a ~==> brewBundle:~ banner and an indented
=$ <command>= line. The script's own warnings start with =brewBundle:=,
and Homebrew's output appears in between. The wrapper never fails the
switch. Failure handling is in
[[file:../how-to/macOS-manage-homebrew.org][Manage Homebrew on macOS]].

* Git identity

This repository defines no identity for the Mac. [[file:../../home/base.nix][home/base.nix]] sets
none, and [[file:../../home/macOS.nix][home/macOS.nix]] only sets
=programs.git.settings.user.useConfigOnly = true=, so that Git refuses
to guess one. The identities come from the Mac's own =identity.nix=.
As [[file:../../templates/macOS/identity.nix][templates/macOS/identity.nix]] ships it:

| Scope          | Selector                                            | Name              | Email                                   | Signing                                                                                       | SSH key                                                                                                                    |
|----------------+-----------------------------------------------------+-------------------+-----------------------------------------+-----------------------------------------------------------------------------------------------+----------------------------------------------------------------------------------------------------------------------------|
| Work (default) | Global =~/.config/git/config=                       | None until filled | None until filled                       | None until filled                                                                             | None selected until filled                                                                                                 |
| Personal       | =includeIf "gitdir:~/src/github.com/piotr-yuxuan/"= | =piotr-yuxuan=    | =piotr-yuxuan@users.noreply.github.com= | OpenPGP, =commit.gpgSign= and =tag.gpgSign=, key =FIXME-personal-openpgp-key-id= until filled | =core.sshCommand= with =-i ~/.ssh/piotr-yuxuan@users.noreply.github.com_ed25519 -o IdentitiesOnly=yes -o ControlPath=none= |

SSH client settings: [[file:../../home/base.nix][home/base.nix]] sets =Host *= (including
=IdentitiesOnly yes= and connection sharing through =ControlMaster=);
[[file:../../home/macOS.nix][home/macOS.nix]] adds =UseKeychain yes= to =Host *=. There is no
=Host github.com= block. Procedures are in
[[file:../how-to/macOS-set-up-work-and-personal-git-identities.org][Set up work and personal Git identities on macOS]].

* Values to fill in

Every value of one Mac lives in that Mac's local flake, by default
=~/src/local/macOS=, never in this repository. The files below are the
Mac's own copies of the template:

| File           | Location                                    | Value                                                                                               | Effect while unfilled                                                                                      |
|----------------+---------------------------------------------+-----------------------------------------------------------------------------------------------------+------------------------------------------------------------------------------------------------------------|
| =flake.nix=    | =user=                                      | Account short name, as printed by =id -un=                                                          | Activation aborts: =error: primary user `example` does not exist, aborting activation=                     |
| =flake.nix=    | =extraHostModules=                          | Machine-local nix-darwin modules, for example a corporate certificate                               | Nothing: the list is empty by default                                                                      |
| =identity.nix= | =programs.git.settings.user=, commented out | Work name and =email=; work signing settings if required                                            | Commits outside =~/src/github.com/piotr-yuxuan/= fail: =no email was given and auto-detection is disabled= |
| =identity.nix= | Comment above =programs.git.includes=       | Work SSH key: =core.sshCommand= for github.com, or a =programs.ssh.settings= block for another host | No key is selected for work remotes                                                                        |
| =identity.nix= | =signingKey= in the personal include        | Long ID of this Mac's personal OpenPGP key, replacing =FIXME-personal-openpgp-key-id=               | Signed commits in personal repositories fail                                                               |
| =identity.nix= | =NH_FLAKE= of the staleness agent           | The local flake's directory, when it is not =~/src/local/macOS=                                     | The agent finds no flake and stays silent                                                                  |

The values of =identity.nix= to fill carry a =FIXME= comment; list them
with =grep -n FIXME identity.nix= in the local flake, and delete each
comment once its value is filled in.
[[file:../how-to/macOS-maintain-the-local-flake.org][Maintain the Mac's local flake]] gives the procedures.

| Proves         | The template and the whole macOS configuration evaluate, Home Manager assertions and activation scripts included      |
| Does not prove | That any =aarch64-darwin= derivation builds, that activation succeeds on a Mac, or anything about a Mac's own modules |

The file holds the same path as
=nix eval --raw '.#darwinConfigurations.macOS.system.drvPath'=, for
example =/nix/store/<hash>-darwin-system-26.05.c3e90c8.drv=. The path
changes only when a file the macOS configuration reads changes,
comments included. A local flake created from the template and left
unchanged evaluates to the same path: the check covers exactly what a
Mac receives before it fills its own values.

The Bats suite [[file:../../tests/macOS/darwin-generated-config.bats][tests/macOS/darwin-generated-config.bats]] complements the
check: it evaluates the same output and runs Git against the identity
settings the template generates. How to run both is in
[[file:../how-to/test-a-change.org][Test a change]].
