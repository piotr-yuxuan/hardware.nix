The entries marked "not published" exist only in the private
repository. The public repository is an export of it, made by
=scripts/publish.py= as [[file:../how-to/publish-to-public.org][Publish to the public repository]] describes.
The files of =publish/overlay/= land at the public root: the licence,
=.gitignore= and the =.github/= directory, which holds the workflow,
the allowlist of the gate, the security policy and the contributing
guide. One file exists in the public repository only: =.version=,
which [[file:release-pipeline.org][the release pipeline]] writes. The personal modules of
nixOS are imported only when they exist;
[[file:../how-to/nixOS-personalise-a-fresh-install.org][Personalise a fresh install of nixOS]] shows how to write them.

* Architecture overview

The flake defines five top-level outputs:

- =nixosConfigurations.nixOS=: full NixOS system (kernel, GNOME, Secure
  Boot via Lanzaboote, LUKS via Disko, hardware tweaks from
  =nixos-hardware=). Home Manager is loaded as a NixOS module.
- =lib.mkDarwinHost=: the builder of a nix-darwin system (macOS
  defaults, Nix daemon, shell registration) with Home Manager loaded as
  a darwin module. It takes =system=, the account name =user=, and the
  module lists =extraHmModules= and =extraHostModules=.
- =templates.macOS=: the starting point of a Mac's own flake. A Mac does
  not clone this repository: its flake takes this one as the input
  =base= and calls the builder, so the account name, the identities and
  any machine-local module stay on that Mac.
- =darwinConfigurations.macOS=: the template evaluated against this
  checkout, placeholders included, so that the check and the tests
  cover what a Mac receives.
- =checks.<system>.darwin-macOS-eval= for =x86_64-linux= and
  =aarch64-darwin=: evaluates that macOS configuration so that
  =nix flake check= covers it without building it.

Both hosts import =home/base.nix= (cross-platform CLI tools, Zsh, Git,
GPG, Starship, direnv, etc.) plus a host-specific layer
(=home/nixOS.nix= or =home/macOS.nix=).

The flake pins two channels:
- =nixpkgs= (stable =nixos-26.05=): system foundation.
- =nixpkgs-unstable=: bleeding-edge packages passed as =unstable= via
  =extraSpecialArgs=.

On macOS, GUI apps are managed through Homebrew (=config/Brewfile=): the
Home Manager activation runs =brew bundle install= automatically.
